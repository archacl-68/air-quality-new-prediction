# Air Quality Prediction

This project analyzes air quality data and predicts air quality using machine learning.

## Models Used
- Linear Regression
- Decision Tree
- Random Forest

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Files
- air_quality_prediction.ipynb - Main Jupyter Notebook
- cleaned_air_quality.csv - Cleaned dataset
- air_quality_predictions.csv - Model predictions
- PNG files - Data analysis and model visualizations

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
